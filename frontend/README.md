# CampusShield Frontend

React 19 + TypeScript + Vite + Tailwind CSS v3 frontend for **CampusShield** (Zero-Trust Campus Document Security Platform).

See the root [README.md](../README.md) for full architecture, roles, Supabase database setup, and deployment instructions.

## Scripts

```bash
npm install     # Install dependencies
npm run dev     # Start local Vite dev server (http://localhost:5173)
npm run build   # Type-check (tsc -b) and build production bundle to dist/
npm run lint    # Run oxlint
```
